# Правила для агентов

Репозиторий публичный. Продукт — тренажёр памяти для курса психологии (студентка — Наталья). Владелец решений — Сергей. Контекст MVP — `docs/kickoff_prompt.md`, план — `docs/plan.md`.

## Перед любым изменением

1. Прочитай этот файл, `docs/plan.md`, `docs/kickoff_prompt.md` и README каталога, который собираешься менять.
2. Изучи уже существующие правила и контракты n8n: `.cursor/rules`, каталог `workflows/`, живой инстанс n8n (MCP/API) и окружение Dokploy/Postgres. Сначала аудит, потом правки.
3. Существующие workflow, контракты узлов и прод-базу оставь рабочими. Попутные переписывания запрещены.

## Подтверждение владельца

Предложи план: файлы, миграции, имена workflow, риски. Дождись явного approve, прежде чем создавать или менять workflow в n8n и прежде чем запускать миграции.

Миграции на проде требуют отдельного подтверждения, даже если план фазы уже одобрен.

До этого подтверждения допустимы документация и локальные черновики в git, если в них нет секретов и материалов курса.

## Секреты

В git не коммитить токены, ключи, `.env`, JSON сервисного аккаунта и credentials n8n. Из экспорта workflow credentials вычищать до коммита. Имена переменных — только в `.env.example`, без значений.

## Материалы курса

В git не коммитить видео, аудио, транскрипты и конспекты реальных лекций. Их место — [папка Google Drive](https://drive.google.com/drive/folders/1FwTgobJc50F4vTe0dxNOaZZTw7QdGnJP) и локальные каталоги `data/` и `tests/fixtures/private/`.

`prompts/konspekt_v1.md` — инструкция модели, её в репозитории держим. Это не конспект лекции.

Термины, определения, детали случаев и факты курса не выдумывать. Источник — транскрипт этой лекции и глоссарий написаний. Дыру ASR помечать `[неразборчиво]`, как в промпте конспекта.

## Язык

Тексты для человека — по-русски: бот, квиз, напоминания, конспект, подписи. Конспект собирать строго по `prompts/konspekt_v1.md`.

## Бюджет

Расходы на работу продукта — не больше 500 ₽ в месяц.

- Whisper только self-host (`large-v3-turbo`, запасной `large-v3`), без платного API распознавания.
- LLM только дешёвая (DeepSeek flash / gpt-4o-mini и аналоги). Каждый вызов писать в журнал токенов.
- Perplexity к этому продукту не подключать.
- Платный API эмбеддингов без отдельного согласия не добавлять.

Если оценка по журналу токенов приближается к потолку — остановиться и спросить владельца.

## Архитектура на вырост

Фаза 2 (озвучка и пауза «дальше», голосовые ответы) в MVP не входит. Схему базы, расчёт FSRS и канал оценки карточки закладывай так, чтобы этот шаг добавился отдельно, без слома утреннего квиза.

## Конец шага

Каждый шаг закрывай коротким чеклистом: что сделано, что проверить, что дальше.
