# prompts

Системные промпты дешёвой LLM (DeepSeek flash / gpt-4o-mini и аналоги). В n8n уходит текст промпта, а не весь файл с комментариями вокруг него.

| Файл | Состояние | Куда попадает |
|---|---|---|
| [konspekt_v1.md](konspekt_v1.md) | в репозитории | system prompt конспекта. В kickoff файл назван `prompts/konspekt.md.sys`; каноническое имя здесь — `konspekt_v1.md`. В модель копируется раздел «Текст system prompt», без шапки и таблицы изменений внизу файла |
| `extract_terms.md` | после approve фазы 1 | извлечение терминов этой лекции |
| `gen_questions.md` | после approve фазы 1 | не меньше 10 жизненных MCQ на подтему |
| `explain_miss.md` | после approve фазы 1 | объяснение ошибки и новый вопрос на тот же термин, если пул вопросов кончился |
| `consolidate_quiz.md` | фаза 2 | смешанный квиз нескольких тем |

Промпты не добавляют фактов, которых нет в транскрипте и глоссарии. Конспекты реальных лекций в этот каталог не кладутся.
