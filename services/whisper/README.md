# services/whisper

Self-hosted faster-whisper: HTTP-сервис распознавания. Платного API речи у продукта нет. Модель по умолчанию — `large-v3-turbo`, запасная — `large-v3`, квантование int8. Ориентир из теста: около 0.15× realtime на 8 CPU. Минимум машины — 4 vCPU и 8 GB RAM, лучше 16 GB.

Dockerfile и код появятся в фазе 1 после approve. Контракт, под который их писать:

- `POST /transcribe`
- вход: аудио (mono 16 kHz; файл или путь на общем диске), `initial_prompt` из глоссария курса, `language=ru`, имя модели;
- выход: полный текст, сегменты с таймкодами, имя модели, длительность.

ffmpeg в этот сервис не входит: нарезку аудио делает workflow `psy_02_extract_audio`. В `initial_prompt` кладутся канонические написания терминов, а не текст лекции. Длинный промпт Whisper обрезает, поэтому список терминов держим коротким.

Медиа в образ и в git не попадают. Каталог на сервере — `DATA_DIR` (локально это `data/`).
