# Kickoff: MVP «память для курса психологии» (фаза 1)

Ты работаешь в **локальном репозитории** Сергея, в agent mode, с доступом к **n8n** (MCP/API) строго по **его rules и contracts**. У тебя **нет** нашего чата и Page-плана — весь контекст ниже.

## Цель

Продукт помогает супруге учить **видеокурс психологии**. Метод студента:

1. **Кодирование** — разъяснение терминов с жизненными примерами → краткий конспект/схемы → ≥10 MCQ из жизни на подтему; при ошибке — объяснение + новый вопрос на тот же термин.
2. **Консолидация** — пауза после учёбы → смешанный квиз 3–4 тем (фаза 2: аудио в машине с паузой «дальше» — **не в MVP**, но не ломай под это архитектуру).
3. **Интервальные повторения (FSRS)** + напоминание про сон вечером.

Оркестрация: **n8n** + **Postgres/Supabase (pgvector)** + **Dokploy** + **Telegram-бот** + **self-hosted faster-whisper** (`large-v3-turbo` / fallback `large-v3`) + **ffmpeg** + **дешёвая LLM** (DeepSeek flash / gpt-4o-mini).

## Бюджет

Opex продукта **≤ ~500 ₽/мес** (замена платного Telegram Whisper). Whisper — **self-host ($0 API)**. LLM — копейки за лекцию. **Perplexity не трогаем** (другие задачи; не в бюджете продукта).

## Железо / ingest (из теста)

Видео ~2–3 GB; аудио 16 kHz mono opus ~5 MB / ~24 мин. Whisper int8 на 8 CPU ≈ **0.15× realtime**. Мин. сервер: **4 vCPU / 8 GB RAM** (лучше 16 GB). Обычный Bot API Telegram = **20 MB** → для больших файлов: **watch папки Google Drive / Яндекс.Диск** (default). Local Bot API — позже, не блокер MVP.

## Порядок работы (обязательно)

1. **Сначала** изучи репозиторий, `AGENTS.md` / `.cursor/rules`, существующие **n8n contracts** и окружение Dokploy/DB. **Ничего не ломай.**
2. Предложи **план фазы 1** (файлы, миграции, workflow names, риски) и **остановись — жди явного approve**.
3. Только после approve: создавать/менять workflow в n8n, миграции, сервисы. **Prod-миграции — только с отдельным подтверждением.**
4. В конце **каждого** шага — короткий checklist deliverables (что сделано / что проверить / что дальше).

## Scope MVP (фаза 1) — acceptance

| # | Критерий |
|---|---|
| 1 | Ingest: новый файл в облачной папке → job в n8n (видео/аудио любого размера в разумных пределах диска) |
| 2 | ffmpeg → mono 16 kHz; вызов Whisper-сервиса с **`initial_prompt` из глоссария курса** |
| 3 | Транскрипт сохранён; LLM-конспект по **приложенному** `prompt_konspekt_v1.md` (вход: МЕТАДАННЫЕ + ГЛОССАРИЙ + ТРАНСКРИПТ) |
| 4 | Извлечение терминов + ≥10 жизненных MCQ на подтему → Postgres |
| 5 | FSRS-карточки; утренний cron due-cards в Telegram |
| 6 | Бот: квиз inline A/B/C/D; ошибка → объяснение + новый вопрос на термин |
| 7 | Вечернее короткое напоминание (лёгкое повторение / сон) — минимально |
| 8 | Регрессия на fixture-лекции; лог токенов LLM; ничего сверх бюджета |

**Вне MVP (фаза 2/3, учесть в схеме, не делать сейчас):** TTS + «дальше», голосовые ответы, аналитика просадки терминов, multi-user, local Bot API.
