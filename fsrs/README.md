# fsrs

Чистый расчёт интервальных повторений. Модуль принимает состояние карточки, оценку (Again / Hard / Good / Easy) и текущее время, возвращает следующее состояние: `due`, `stability`, `difficulty`, `state`, счётчики повторов. Сети, базы и Telegram внутри нет.

В MVP квиз мапит ответ так: ошибка → Again, верный ответ → Good. Поля Hard и Easy в расчёте остаются, чтобы не переделывать карточки позже.

Библиотека или короткий порт алгоритма FSRS выбирается на реализации: без сети в рантайме, с тестами на фиксированных датах. Кода здесь пока нет — только граница модуля, чтобы workflow n8n вызывали одну функцию, а не считали интервал в узлах.
