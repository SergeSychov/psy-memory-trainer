# bot

Telegram-бот для Натальи: утренние due-карточки FSRS, квиз кнопками A/B/C/D, при ошибке — объяснение и новый вопрос на тот же термин, вечером — короткое напоминание про лёгкое повторение и сон.

В kickoff каталог назван `services/bot`. Канонический путь здесь — `bot/`. Если хватает webhook n8n (`psy_07`…`psy_09` в [workflows](../workflows/README.md)), отдельный процесс не заводим, а в этом каталоге остаются тексты сообщений и контракт кнопок. Отдельный сервис появляется, только если логика перестаёт помещаться в n8n.

Тексты бота — по-русски. Токен бота живёт в credentials n8n и в локальном `.env`, в git его нет.

Канал оценки карточки — запись в `reviews` и чистый пересчёт в `fsrs/`. Так фаза 2 (голос, пауза «дальше») сможет поставить ту же оценку, не переписывая квиз.
